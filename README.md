# GLOWDRINKS - HỆ THỐNG QUẢN LÝ VÀ BÁN ĐỒ UỐNG TRỰC TUYẾN

Dự án website kinh doanh đồ uống (trà sữa, cà phê, nước ép) tích hợp cổng quản trị, mini game và công cụ tự động chẩn đoán - khắc phục lỗi hệ thống.

---

## 🚀 KHỞI ĐỘNG NHANH
Nhấp đúp chuột vào file **[`start.bat`](start.bat)** tại thư mục gốc:
- Bấm **`[1]`**: Tự động chẩn đoán, kích hoạt MySQL/WampServer và mở website.
- Bấm **`[7]`**: Mở bảng điều khiển Frontend Dashboard ([`control_panel.php`](Trang%20chinh/control_panel.php)).

---

## 📜 LỊCH SỬ DỰ ÁN & NHẬT KÝ HOẠT ĐỘNG
- **Nhật ký phát triển & Phiên bản**: Xem chi tiết tại **[`CHANGELOG.md`](CHANGELOG.md)**.
- **Nhật ký vận hành hệ thống (Runtime Log)**: Xem tại **[`history.log`](history.log)** (file được tự động ghi nhận mỗi khi khởi động hoặc chẩn đoán hệ thống).
